# podpis

Obrázky do e-mailových podpisů EffiStream, servírované přes GitHub Pages:
`https://effistream.github.io/podpis/<soubor>`

Odkazují na ně už odeslané e-maily. Repozitář ani soubory proto nemazat a nepřejmenovávat.
Změna souboru pod stejným jménem se projeví i ve starých e-mailech (jakmile vyprší cache).

Zdroj a nástroje: `effistream.knowledge/email-podpisy` (složka `podpis/` = tyto soubory).
Zatím je tu jen varianta v2 (Vektorové pole).
